Crea tu viaje

Rellena los datos, sube tus fotos y genera una página lista para publicar en GitHub Pages. Cada viaje se convierte en su propio sello — y su propia URL — que tu etiqueta NFC podrá abrir.

02Lugares visitados

Cada lugar se convierte en un sello de pasaporte en la página final.

03Fotos

Súbelas todas de golpe. Se incluyen dentro de la propia página, así que no necesitas subir imágenes a ningún otro sitio.

04Generar

Se descargará un único archivo HTML con todo dentro: fotos, lugares y diseño. Solo tienes que renombrarlo a index.html y subirlo a la carpeta de este viaje en tu repositorio.

05Publicarlo en GitHub Pages

  1. Crea un repositorio en GitHub, por ejemplo viajes.
  2. Sube este index.html, style.css y script.js a la raíz — esa será tu página para crear futuros viajes.
  3. Por cada viaje generado, crea una carpeta con el slug elegido, ej. londres-2026/, y dentro coloca el archivo descargado renombrado como index.html.
  4. En Settings → Pages, activa GitHub Pages sobre la rama main.
  5. Tu viaje quedará publicado en https://tuusuario.github.io/viajes/londres-2026/ — esa es la URL que grabas en el NFC.
